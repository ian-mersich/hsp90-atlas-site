# HSP90 Atlas release changelog

## Atlas v1.6.441 — 2026-10-04

Two existing AIP findings were corrected in place after source re-review. An AHR-baited tandem-affinity purification/mass-spectrometry experiment (PMID 24454361) supports weak co-recovery of AIP with HSP90 machinery in mouse Hepa1c1c7 cells. It does not establish pairwise AIP–HSP90 binding, occupancy of the same individual complex, a comparison between HSP90α and HSP90β, or HSP90-dependent AIP client activity. A second paper (PMID 20829355) addresses AIP loss in a mouse hepatocyte/AHR toxicology model; its AIP–HSP90 statement is cited background, not an HSP90 assay in that study. The unavailable supplement prevents whole-source closure for that paper.

Both findings retain their source links and explicit caveats, but neither enters final scoring. This is an interpretation correction, not a new source, pair, client assignment, numerical score, rank, readiness decision, or analytical-profile update. The release retains 5,093 tracked pairs and 4,142 source findings.

The Interactive HSP90 Cycle payload and its scientific source horizon remain the v6.440 targeted review over the v6.303 model. Only the Cycle manifest's public Atlas release label changes to v6.441. Affected HPA/CPTAC summaries and the optional bulk database-observation layer remain withheld.
