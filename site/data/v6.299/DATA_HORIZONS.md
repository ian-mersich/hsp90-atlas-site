# HSP90 Atlas v6.299 data horizons

The v6.299 Atlas release combines two related but biologically distinct evidence surfaces under one release identifier.

- The HSP90 gene–isoform browser uses the cumulative source-gene layer through v6.254: 5,092 HSP90 isoform–gene relationships and 3,922 reviewed source–gene findings.
- The co-chaperone network download uses the canonical v6.299 review boundary: 389 source-specific findings across 286 reviewed co-chaperone or partner pairs and 71 primary sources.
- Detailed HPA 25.1 and BioGRID/IntAct profile files remain the validated v6.109 analytical sidecar over the original 4,325-pair v6.104 universe. A missing detailed profile for a newer relationship is not negative evidence.

Co-chaperone–co-chaperone and co-chaperone–partner findings are not recast as HSP90 isoform–gene assertions. Their source-specific assay ceilings, direction, experimental systems, organisms, compartments, limitations, and evidence-zero scoring boundary are preserved in the separate download.

Coverage remains non-comprehensive. Database records and correlations are discovery context unless supported by reviewed primary-source evidence. This release does not create a final score, final rank, pathway interpretation, or scored reference set. The HSP90 cycle explorer and all public Atlas surfaces use the same v6.299 release label; older component horizons remain available only as provenance in the release manifest.
