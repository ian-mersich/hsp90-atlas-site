# HSP90 Atlas release changelog

## Data v6.438 release — 2026-10-02

This release carries forward the v6.437 source-reviewed dataset and resolves the existing HSP90B1–LDLR source review for PMID 40868968 as support-only evidence. The source record is limited to what the study measured: it does not establish unmeasured turnover, and lysate CETSA, abundance changes, and drug-specific responses are not interpreted as direct binding, client status, or general target specificity.

- No new source findings or tracked pairs are added in this slice.
- The LDLR resolution is support-only and does not add score points, ranking eligibility, direct-binding promotion, or client promotion. Existing scores and ranking semantics are preserved.
- The v6.303 reviewed-cycle and v6.301 co-chaperone horizons remain unchanged. Affected HPA/CPTAC summaries and private bulk-cycle observations remain withheld.
- Release validation and publication status are documented separately from the scientific scope described here.
