# HSP90 Atlas v6.300 data horizons

The v6.300 Atlas release combines two related but biologically distinct evidence surfaces under one release identifier.

- The core HSP90 isoform atlas remains the cumulative v6.254 evidence layer: 5,092 gene–isoform relationships and 3,922 source-reviewed findings.
- The co-chaperone network download uses the canonical v6.300 review boundary: 398 source-specific findings across 294 reviewed co-chaperone or partner pairs and 72 primary sources.
- PMID 29568061 contributes nine exact MAC-tag assay rows. AP-MS is represented as cellular co-purification or shared-complex context; BioID is represented as proximity. Neither is promoted to direct binding, HSP90 client status, or productive cycle evidence without orthogonal support.
- Three PMID 29568061 AP-MS rows have row-level BFDR values of 0.08–0.09 despite meeting the source's SAINT 0.73 inclusion boundary. They remain explicitly threshold-edge, context-only findings with zero production-score contribution.
- The analytical-profile sidecar remains the validated v6.109 analysis over the original v6.104 pair universe; it is not silently expanded to the current core universe.
- The private cycle explorer retains its v6.294 cycle-model component and v6.286 reviewed-neighborhood component while presenting the unified v6.300 shell release.

Coverage remains non-comprehensive. Database records and correlations are discovery context unless supported by reviewed primary-source evidence. This release does not create a final score, final rank, pathway interpretation, or scored reference set. All public Atlas surfaces and the private cycle explorer use the same v6.300 release label; older component horizons remain available only as provenance in the release manifest.
