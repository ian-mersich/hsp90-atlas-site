# HSP90 Atlas v6.303 data horizons

The v6.303 Atlas release keeps the public evidence browser and the interactive HSP90-cycle explorer under one release identifier while preserving the provenance of each evidence layer.

- The core HSP90 isoform atlas remains the cumulative v6.254 evidence layer: 5,092 gene–isoform relationships and 3,922 source-reviewed findings.
- The public co-chaperone network remains at the canonical v6.301 review boundary: 457 source-specific findings across 351 reviewed co-chaperone or partner pairs and 72 primary sources.
- The cycle model advances to v6.303 with 66 nodes and 214 edges. Thirteen non-client machinery relationships were added after pair-specific source review: ten cycle-detail edges and three optional neighborhood-context edges.
- PIH1D1–RUVBL1 and PIH1D1–RUVBL2 are represented as R2TP structural-complex co-memberships supported by replicated cellular co-recovery. They are not presented as resolved direct binary contacts.
- BioPlex 1.0, BioPlex 2.0, and the BioPlex 3.0 293T arm are treated as one evolving experimental program. The BioPlex 3.0 HCT116 arm supplies a separate cross-lineage measurement; repeated database encodings do not increase source weight.
- The DNAJB11–HSPA1A database projection remains excluded because its cited source did not resolve the inducible Hsp72-family signal to HSPA1A.
- The cycle explorer retains the v6.286 reviewed-neighborhood component as a provenance-bounded context layer. The newly added cycle edges carry 32 supportive pair-source reviews directly in the cycle evidence registry.
- The analytical-profile sidecar remains the validated v6.109 analysis over the original v6.104 pair universe; it is not silently expanded to the current core universe.

Coverage remains non-comprehensive. Database records and correlations are discovery context unless supported by reviewed primary-source evidence. This release does not create a final score, final rank, pathway interpretation, or scored reference set. All public Atlas surfaces and the cycle explorer use the same v6.303 release label; older component horizons remain available only as provenance in the release manifest.
