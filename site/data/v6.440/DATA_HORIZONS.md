# HSP90 Atlas v1.6.440: evidence scope

The current release contains 5,093 tracked gene–isoform pairs and 4,142 source findings. Of the pairs, 2,794 are source-reviewed, 2,313 carry the legacy positive-source-evidence flag, 136 are reviewed exclusion-only, and 2,299 remain discovery leads. The source-linked network contains 2,311 records. These counts do not indicate direct binding or client status.

Two support-only findings from PMID 26628375 add GRP94–PCSK9 association and PCSK9-conditional protection of LDLR abundance. Both pairs were already tracked. All prior numerical scores, ranks, readiness fields and final-reference assignments are unchanged. LDLR now has four visible findings but retains its two-record historical score input; PCSK9 remains unranked.

The reviewed Cycle graph retains the v6.303 structural model and adds one source-specific cellular IP-MS context from PMID 35271311 to HSPA8–STIP1. This is a targeted source update, not an exhaustive re-review of every Cycle relationship. The new source supports co-recovery, not pairwise binding, cycle-stage timing or HSP90 client transfer. It is not counted again as an independent database study. Prior source records and graph metadata remain unchanged. The reviewed neighborhood remains v6.286 and the co-chaperone component v6.301.

Detailed HPA and BioGRID/IntAct analytical profiles remain the v6.109 carry-forward over the historical v6.104 pair universe. The prior HSP90B1–PCSK9 and HSP90B1–FLT3 additions still have no detailed historical profile; absence is not negative evidence. This release adds no new pairs. Affected HPA/CPTAC summaries and private bulk Cycle database observations remain withheld.
