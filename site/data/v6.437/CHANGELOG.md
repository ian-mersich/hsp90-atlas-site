# HSP90 Atlas release changelog

## Data v6.437 public release — 2026-10-02

Data v6.437 adds four source-reviewed support findings to 5,091 tracked pairs and 4,137 source findings. They include cellular GRP94–TLR9 association and receptor-response evidence (PMID 17275357), extracellular gp96-induced NLRP3 abundance and inflammasome-response evidence (PMID 30209191), partial TRAP1 rescue of mitochondrial membrane potential after PINK1 loss (PMID 29050400), and a PINK1-dependent basal TRAP1 abundance response (PMID 22076283). These findings do not establish direct binding, phosphorylation, protein stability, or client status.

- The release has 2,792 source-reviewed pairs, 2,311 carrying the legacy positive-source-evidence flag, 136 reviewed exclusion-only pairs, and 2,299 discovery leads. Its source-linked network contains 2,309 records.

- All four additions are support-only, with no new score points, ranking eligibility, direct-binding promotion, or client promotion.
- Existing v6.303 reviewed-cycle and v6.301 co-chaperone horizons remain unchanged. Affected HPA/CPTAC summaries and private bulk-cycle observations remain withheld.
- This changelog describes the public Data v6.437 package. Independent live-site QA and deployment verification are tracked separately and are not claimed here.
